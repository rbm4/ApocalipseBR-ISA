# Issue records

Create `I-NNN-short-name.md` when recording a concrete defect or investigation. Include:

- Title, ID, date, status (`investigating`, `ready`, `in progress`, `resolved` or `deferred`).
- Observed behavior, expected behavior, reproduction or source evidence, and impact.
- Relevant files/symbols, root cause or unresolved questions, and related report/feature links.
- Proposed correction, compatibility implications, acceptance checks and actual validation results.

Update [the index](../INDEX.md). Do not mark a source-only hypothesis as a reproduced runtime failure or a planned correction as resolved.
