# Feature records

Create `F-NNN-short-name.md` for an intended capability or substantial behavior change. Include:

- Title, ID, date, status (`proposed`, `ready`, `in progress`, `implemented` or `deferred`).
- User/server outcome, scope, requirements and explicit design choices.
- Architecture, lifecycle/data flow, authoritative state and bounded work.
- Save migration, network/client compatibility, dependency effects and failure recovery.
- Acceptance criteria, actual implementation references and validation results.

Update [the index](../INDEX.md) and link relevant issues/reports. Separate planned architecture from the behavior shipped in the current mod.
